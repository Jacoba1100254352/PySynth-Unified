==========
Python API
==========

The recommended import is ``pysynth``. It exposes ``make_wav``,
``SynthConfig``, ``ProgressConfig``, ``available_sounds``, and ``parse_song``.
The same rendering API remains available from ``tomita`` for compatibility.
